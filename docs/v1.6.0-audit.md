## 五、落地服务与同类数据丢失

### SS ↔ SOCKS5 丢配置的完整原因

这是数据模型、规范化和前端保存共同造成的，不能仅修显隐逻辑。

1. **数据模型只能保存一套远端配置。**  
   `deploy/panel/main.go:99` 的 `LandingService` 只有一套 `remote_host`、`remote_port`、`remote_password`。SS 和 SOCKS5 切换后填写的新地址、端口、密码会覆盖原协议，没有第二份可恢复配置。

2. **保存及启动时主动删除另一协议的字段。**  
   `deploy/panel/handlers.go:2483`：SOCKS5 清空 `remote_method`，SS 清空 `remote_user`。  
   `deploy/ansgo-genconf:124` 做同样的清理并可能写回 `panel.json`。  
   `deploy/panel/main.go:492` 启动迁移也调用此逻辑。因此通过 API 留住隐藏字段，仍可能在下一次保存、genconf 或启动时被清除。

3. **两个密码输入框实际上来自同一个值。**  
   `deploy/panel/web/index.html:789`、`:793` 把同一 `remote_password` 分别放进 SS 和 SOCKS5 密码框。它们不是两套已持久化密码。

4. **前端只提交当前协议的字段。**  
   `deploy/panel/web/index.html:855`：SOCKS5 只提交 user＋其密码框；SS 只提交 method＋其密码框。单纯“未提交隐藏字段”本来不会清空后端指针字段，但后续 normalize 会清空它们。

5. **切换本身只显隐，保存后的整页重绘才让旧草稿消失。**  
   `deploy/panel/web/index.html:809` 只是修改 display；尚未保存时切回，DOM 中的值一般还在。保存后 `loadLanding()` 重建所有卡片，旧草稿被服务器当前唯一配置替代。再次切回 SS 时，原加密方式通常只能回到默认值，原 SOCKS 用户名也无法恢复。

**D01 / P1 建议：** 每个落地保存 `remote_type` 及独立的 SS、SOCKS5 配置对象；切类型只改变生效选择，不删除另一协议。迁移旧字段到当前协议对象，生成器只读取、不修改源配置。新 UI 为两类协议分别维护草稿和保存状态。

### 通用约定

- 所有路径均为 **`<url_path>api/...`**，不是站点根 `/api/...`；前端使用相对路径。
- 除 auth/login 外均要求 `bv_sess` Cookie。Cookie 为 Secure、HttpOnly、SameSite=Strict，Path 为 `/`。
- JSON 字段名和类型按以下实际实现保留。尤其：dashboard 的 port 是数值，health 的 port 是字符串；配置中的部分开关是 `"true"/"false"` 字符串，API 的 enabled 通常是布尔值。
- 普通错误为 `{error:string}`；未登录为 HTTP 401。部分接口使用专有错误结构，不能只检查是否存在 `error`。
- 下表方法为现有 UI 用法。**settings 和 cert/config 实现为 GET 读取、其他方法进入写分支；多个纯读取 handler 也没有方法限制。** 重写时应明确服务端方法契约。

为完整列出嵌套响应，使用以下对象名称：

| 对象 | 字段 |
|---|---|
| `Cert` | 成功：`subject:string, issuer:string, issuer_org:string, not_before:string, not_after:string, days_left:number`；解析失败：`error:string`。日期格式 `YYYY-MM-DD` |
| `TimeDiag` | `now_local:string, now_utc:string, timezone:string, offset:string, ntp_synchronized:string, detail?:string`；NTP 可能为 `yes/no/unknown/host` |
| `Landing` | `id:string, name:string, enabled:bool, port:number, has_keys:bool, password:string, uuid:string, remote_enabled:bool, remote_type:string, remote_host:string, remote_port:number, remote_method:string, remote_password:string, remote_user:string, remote_via:string` |
| `URIs` | 字符串映射：可能含 `ss, anytls, socks, naive, landing-<id>`；凭证缺失或落地未启用时相应键可缺失 |
